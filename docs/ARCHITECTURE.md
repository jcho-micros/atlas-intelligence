# Atlas Architecture

Atlas is moving toward an AI Commerce Operating System.

```text
Research → Candidate Project → CEO Approval → Business → Products → Departments → Launch
```

## Core objects

- Business: the operating unit.
- Brand: the customer-facing identity.
- Product: a sellable concept within a business.
- ProductProject: execution workspace for a product.
- AgentTask: work assigned to an agent.
- AgentEvent: permanent activity history.
